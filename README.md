# climatevar

A Python library for reproducible climate and atmospheric science analysis.

## Vision

`climatevar` is being developed as a research-grade toolkit for climate variability, atmospheric diagnostics, hydroclimate extremes, statistical analysis, and reproducible scientific workflows.

The project prioritizes:

- scientifically transparent methods
- xarray-first multidimensional data handling
- explicit units and metadata
- reproducible calculations
- well-tested statistical methods
- publication-ready workflows and diagnostics

## Development status

🚧 Early development — API may change.

## Planned capabilities

- Climate variability and climatology
- Precipitation and hydroclimate indices
- Extreme-event analysis
- Trend and significance testing
- Atmospheric thermodynamics
- Spatial and temporal analysis
- ERA5 / NetCDF / GRIB workflows
- WRF-oriented utilities
- Scientific visualization
